# T.C. İçişleri Bakanlığı
## Yataktan Sarkan Ayak Sınır İhlali Genel Müdürlüğü

### Genelge No: YSA-2608/HUDUT/2026

Bu müdürlük, uykunun kırk birinci dakikasında battaniyenin dışına çıkan her ayağı sıradan bir üşüme değil, **kara sınırı ihlali** sayar.

Battaniye hudut hattıdır. Yastık karakoldur. Çarşaf tampon bölgedir. Ayak, vizesiz geçiş yapan yabancıdır.

---

## Resmi Tanımlar

| Olay | Hudut Karşılığı |
|---|---|
| Tek ayak dışarıda | İdari para cezası / uyarı atışı |
| İki ayak dışarıda | Fiili ihlal — devriye çağrıldı |
| Battaniyenin yere düşmesi | Sınır kapısının açık unutulması |
| "Üşüdüm" demek | Sığınma talebi (ön inceleme) |
| Eşin battaniyeyi çekmesi | Tek taraflı sınır değişikliği |
| Çorapsız geçiş | Belgesiz seyahat |
| Sabah 06:12'de geri çekme | Gönüllü iade protokolü |

---

## Kuruluş Amacı

Bilim, vücut ısısının ekstremitelerde düştüğünü söyler. Bu müdürlük bilimi tanır, fakat **hududu ısının üstünde** tutar.

Her sarkma kayda geçer. Kayıt silinmez. Kayıt damgalanır. Ayak pişman olsa bile evrak pişman olmaz.

---

## Kullanım

```bash
python3 sinir_ihlali.py
python3 sinir_ihlali.py --ayak "sol başparmak"
python3 sinir_ihlali.py --derece 2 --usume 7
python3 sinir_ihlali.py --es-cekti
```

Program gerçekten çalışır. Sarkma tespit edilir, ihlal puanı hesaplanır, gerekirse sığınma dosyası açılır, sonunda damga basılır.
